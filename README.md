# alexshypula.github.io

Personal site, built with Jekyll's [Minima](https://github.com/jekyll/minima) theme on GitHub Pages.

- `index.md` — the home page. Publications are rendered from `_data/publications.yml`.
- `projects.md` — sub-page linking to projects (not linked from the home page).
- `ai-equity/` — "Who ends up owning AI?", a static d3 app with its model source alongside. See its README.

Local preview: `bundle install && bundle exec jekyll serve --livereload`, then open http://127.0.0.1:4000/.
